# Примеры тест-кейсов на разные API: REST API, GraphQL, gRPC

## Тест-кейс для REST API

| Тест-кейс           | TR001: создание пользователя с валидными кредами                                                                                                       |
|---------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| Описание            | Проверить создание пользователя через REST API                                                                                                         |
| Предусловия         | Сервер запущен и работает корректно, пользователь<br/>с email **testuser@gmail.com** не существует                                                     |
| Шаги                | 1. Отправить POST-запрос на эндпоинт **/api/users** с телом:<br/> {"name": "TestUser","email": "testuser@gmail.com"}                                   |
| Ожидаемый результат | 1. Статус ответа сервера 201 Created<br/>2. Тело ответа формата JSON с полями: createdAt, email, id и name<br/>3. Запись о пользователи появилась в бд |

## Тест-кейс для GraphQL API

| Тест-кейс           | TG003: создание заказа                                                                                                                                             |
|---------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Описание            | Проверить создание заказа через GraphQL API                                                                                                                        |
| Предусловия         | В БД существует пользователь с id=1 и продукт с id=1, у которого stock > 0                                                                                         |
| Шаги                | 1. Отправить POST-запрос на эндпоинт **/graphql** с телом:<br/> {"query": "mutation { createOrder(input: {userId: 1, productId: 1, quantity: 2}) { id status } }"} |
| Ожидаемый результат | 1. Статус ответа: 200 OK<br/>2. В поле data.createOrder содержится id и status: "PENDING"<br/>3. В БД создан новый заказ, остаток товара уменьшен на 2             |

## Тест-кейс для gRPC API

| Тест-кейс           | TP004: просмотр заказа                                                                                                 |
|---------------------|------------------------------------------------------------------------------------------------------------------------|
| Описание            | Проверить информацию о заказе через gRPC API                                                                           |
| Предусловия         | В БД существует заказ с id=1 и продукт с id=1                                                                          |
| Шаги                | 1. Выполнить команду:<br/>grpcurl -plaintext -d '{"id":1}' localhost:9090 com.example.grpc.order.OrderService/GetOrder |
| Ожидаемый результат | 1. Тело ответа формата JSON с полями: id, user_id, product_id, quantity, order_date и status                           |
