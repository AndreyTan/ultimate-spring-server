# Чек-лист: Дымовое тестирование Ultimate Spring Server

## 1. REST API (Базовый URL: http://localhost:8081/api)

### Пользователи (/users)
- **GET /users** - Статус ответа 200, список пользователей не пуст
- **POST /users** - Создание пользователя, статус 201, возвращён ID
- **GET /users/{id}** - Получение существующего пользователя, статус 200
- **GET /users/{id}** - Запрос несуществующего пользователя, статус 404
- **PUT /users/{id}** - Обновление данных, статус 200

### Продукты (/products)
- **GET /products** - Статус 200, список продуктов получен
- **POST /products** - Создание продукта, статус 201
- **GET /products/{id}** - Получение продукта по ID, статус 200

### Заказы (/orders)
- **POST /orders** - Создание заказа, статус 201, остаток товара уменьшен
- **GET /orders** - Статус 200, список заказов получен
- **GET /orders/{id}** - Получение заказа по ID, статус 200
- **PUT /orders/{id}/status** - Обновление статуса на "SHIPPED", статус 200

## 2. GraphQL API (Эндпоинт: http://localhost:8081/graphql)

- **Query: users** - Запрос списка пользователей, данные получены
- **Query: ordersByUser** - Запрос заказов по userId, данные получены
- **Mutation: createOrder** - Создание заказа через мутацию, статус "PENDING"

## 3. gRPC API (Сервер: localhost:9090)

- **OrderService/CreateOrder** - Создание заказа через grpcurl, получен ID
- **OrderService/GetOrder** - Получение заказа по ID, данные корректны
